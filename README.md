# S0UL VINYL

مشغّل أغاني لديسكورد. يتّصل Bot الصوت مباشرة بالروم عبر discord.js/voice، ويستخدم yt-dlp وFFmpeg لقراءة الصوت. اختاري لغة أول أمر تشغيل لتحديد لغة البطاقة المشتركة في السيرفر.

## أول تشغيل في GitHub Codespaces

استخدمي Node.js 24 أو أحدث. من تيرمنال المشروع شغّلي:

```bash
npm run setup
npm start
```

أمر الإعداد يثبت FFmpeg وyt-dlp ومكتبات Node وينشئ ملف `.env` إذا احتجتِه. ضعي توكن تطبيق البوت بعد `DISCORD_TOKEN=` في هذا الملف أو في سرّ Codespaces بنفس الاسم. `DISCORD_GUILD_ID` اختياري لتسجيل الأوامر في سيرفر تجربة. يحتاج البوت صلاحيات عرض الروم، إرسال الرسائل والمرفقات، والاتصال والتحدث.

## تجربة البطاقة

ادخلي رومًا صوتيًا عاديًا، شغّلي أغنية ثم أضيفي أغنية ثانية لها غلاف مختلف. عند انتهاء الأولى يكمل البوت تلقائيًا ويحدّث الرسالة نفسها. تقدرين تجرّبين التغيير فورًا بزر التخطي. عند الإيقاف المؤقت يثبت الفاينل وتستمر النجوم. إذا تعذر تحميل غلاف الأغنية الحالية تظهر أسطوانة بملصق VINYL.

| عربي | English | الوظيفة |
|---|---|---|
| /شغل | /play | تشغيل أو إضافة أغنية |
| /تخط | /skip | التالي |
| /سابق | /back | السابق |
| /مؤقت | /pause | إيقاف مؤقت أو استئناف |
| /وقف | /stop | إيقاف الجلسة والخروج |
| /صف | /queue | عرض قائمة الانتظار |

## المصادر

البحث بالاسم يعرض حتى خمس نتائج من SoundCloud. يعرض عنوان التسجيل والحساب الذي رفعه والمدة عند توفرها، ويضيف اختيار المستخدم فقط. يقبل البوت روابط عامة من SoundCloud وYouTube وBandcamp وVimeo وMixcloud وTwitch حيث يتاح الصوت للمستضيف. بعض الروابط تتطلب تسجيل الدخول أو تكون مقيدة. عند تعذّر YouTube يحاول إيجاد نسخة مطابقة في SoundCloud.

لرابط أغنية Spotify أو Apple Music يقرأ البوت بيانات الأغنية ويبحث عن نسخة في SoundCloud. تظهر قائمة خاصة لاختيار تسجيل من SoundCloud، ويفتح رابط البطاقة التسجيل المختار. روابط الألبومات والقوائم في هاتين الخدمتين غير مدعومة. يعتمد توفر الغلاف ورابط الفنان على بيانات المصدر.

قائمة الانتظار محفوظة أثناء جلسة التشغيل. بعد إعادة تشغيل البوت ابدئي جلسة جديدة. للأجهزة الأخرى ثبتي Node.js 24 وFFmpeg وyt-dlp ثم مكتبات npm. يستخدم البوت المسار المحلي .venv/bin/yt-dlp أو yt-dlp من PATH.
